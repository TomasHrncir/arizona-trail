## Jak nasadit

1. Stáhni MP3 kterýkoliv track
2. Přejmenuj na `desert.mp3`
3. Přesuň sem do `public/audio/`
4. Refresh prohlížeč — klikni na reproduktor vpravo dole

Kód automaticky loopuje. Klávesa **M** zapíná/vypíná.

## Formáty

- Ideálně MP3, 128 kbps stačí (pod 4 MB)
- WAV je moc velké
- Delší track (3-6 min) je lepší, loop nezaznamenáš tak snadno
